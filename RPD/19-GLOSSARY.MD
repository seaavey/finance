## 19. Glossary

| Istilah             | Arti                                                              |
| ------------------- | ----------------------------------------------------------------- |
| **Base Currency**   | Mata uang utama user (dari `profile.currency`)                    |
| **Bento-Grid**      | Layout dashboard dengan grid asimetris (seperti Bento UI)         |
| **Couple Mode**     | Fitur berbagi data finansial dengan pasangan via undangan email   |
| **RLS**             | Row-Level Security — kebijakan akses baris di PostgreSQL/Supabase |
| **Edge Function**   | Deno function serverless di Supabase                              |
| **shadcn-vue**      | Port Vue dari shadcn/ui — komponen yang di-copy ke codebase       |
| **TanStack Query**  | Library server state management (sebelumnya React Query)          |
| **Unovis**          | Library chart visualisasi untuk Vue/React/Svelte                  |
| **RPC**             | Remote Procedure Call — fungsi PostgreSQL yang dipanggil via API  |
| **Signed URL**      | URL sementara dengan expiry untuk akses private storage           |
| **Fire-and-forget** | Panggilan async yang tidak di-await (best-effort)                 |
| **StaleTime**       | Waktu sebelum TanStack Query refetch data                         |
| **Rolldown**        | Rust-based bundler, default di Vite 8                             |
